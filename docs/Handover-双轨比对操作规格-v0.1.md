# Handover · 双轨比对操作规格（v0.1）

- **定位**：DEP-09"双轨并行两周逐日比对"的**执行规格**——比对什么、怎么判差异、差异怎么闭环、什么条件停纸转单轨。Phase 1 里程碑验收的唯一执法工具，任务分解 TK-33 的正式交付物。
- **上游文档**：《PRD v0.2.8》§8 上线考虑、《规格台账 v1.4》DEP-09 / DEP-11、《技术方案 v0.2》§10、《开发种子数据 v0.1》（预演数据源）
- **生成时间**：2026-09-01
- **状态**：v0.1 初稿；❓ 标注项为建议值，**双轨启动前与科长确认后转正**（对齐台账纪律：确认后回写升版本）

## 1. 机制总览

| 项 | 约定 |
| --- | --- |
| 双轨期 | 纸质单与电子单**同日同内容**各自填写，连续 **14 天** ❓（建议值，与达标线一同由科长确认） |
| 填写主体 | 师傅照常填纸质单；电子单独立填写——**不誊抄**（誊抄会掩盖真实差异，双轨的目的之一就是暴露两侧各自的真实差错） |
| 比对节奏 | 每日一次，次日 12:00 前完成，比对**前一班次**的全部字段 |
| 比对主体 | 科长牵头 + 当班师傅到场核实 |
| 电子侧取数 | 一律从后台导出（F6-01），**禁止看屏手抄**（手抄会引入第三种差错源） |
| 法律效力 | 双轨期**纸质单仍是正式凭证**，电子单并行验证；转单轨后电子单为唯一凭证（条件见 §5） |

## 2. 比对范围与粒度

逐字段比对，范围 = 一份完整交接单的全部内容：

1. 十个板块全部原始读数与状态字段（按 PRD 附录 A 逐字段）
2. 电梯逐台核对结果（预期 / 实际 / 说明）
3. 交接事项原文
4. 派生字段（四类用量）——单独比对，差异分类见 §3-B
5. 责任字段：交班人 / 接班人（交接时间纸质无精确时刻，不比对）

**比对表结构**（每日一张，建议 Excel，列固定，随上线材料归档）：

| 列 | 说明 |
| --- | --- |
| 班次日期 / 板块 / 字段 | 定位 |
| 纸质值 / 电子值 | 原样抄录，不改写 |
| 一致？ | 是 / 否 |
| 差异分类 | A 抄录差 / B 计算差 / C 口径差 / D 系统缺陷（§3） |
| 处理动作 | 修正侧 / 挂起 / 记 bug 等 |
| 责任人 / 闭环时间 | 每条差异必填 |

## 3. 差异分类口径（核心）

| 分类 | 定义 | 处理 | 计入通过率分母？ |
| --- | --- | --- | --- |
| **A 抄录差** | 原始读数纸电不一致（填写时就不同） | 当日与师傅到表现场核实，以表计真实值为准修正错误一侧；同一字段连续两天出现 A 类 → 检查该字段布局是否易看错（C-02） | 计入 |
| **B 计算差** | 原始读数一致、用量不同（纸质手算错） | **以系统为准，纸质侧不改**，记录即可——这正是系统的价值（PRD §2"手算易错"是立项理由；v0.2.7 比对已印证：纸面电量 35850 实为两线之和而非差值、液氧 0.5 与差值 0.3 不符） | **不计入**（预期恒存在） |
| **C 口径差** | 待确认项未闭环导致（如 DATA-12 液氧单位） | 挂起并标注关联规格编号；确认后自然消除；该字段剔除出当日分母 | **剔除分母** |
| **D 系统缺陷** | 系统漏算 / 错算 / 丢数据 / 同步失败 | 记入缺陷清单（编号 `BUG-序号`）→ 修复 → 回验对应 `-T` 用例；**双轨期内 D 类必须全部闭环** | 计入 |

## 4. 每日通过率与达标线

- 当日字段一致率 = 一致字段数 ÷（参与字段总数 − C 类挂起字段 − B 类预期差）
- 达标线：**连续 14 天一致率 ≥ 98%** ❓（建议值，启动前与科长确认）
- B 类差异单独统计、随周呈报科长——它是系统价值的证据，不是缺陷，不需要"消灭"

## 5. 转单轨条件（全部满足才停纸）

1. 连续 14 天每日一致率达标（§4）
2. 无未闭环的 D 类差异；A 类无同一字段连续两天复发
3. C 类挂起全部消除，或经科长书面豁免
4. 培训完成（DEP-10：全员到场 + 操作卡片发放，见手工验收检查单 §六）
5. 科长签字确认；纸质单据归档封存（留存按 DEP-03）

## 6. 双轨期间的特殊规则

- **撤回 / 异议只走电子流程**：纸质单如有划改按原纸质规范处理，不要求两侧流程对齐
- **签名**：纸电各自签名（电子签名实名口径 C-05 不变）
- **预警**：Phase 1 标红项以电子为准；微信群人工转发过渡措施照常执行（DEP-12）
- **比对记录归档**：14 张比对表 + 差异处理记录随上线材料归档，作为 DEP-09 的验收凭证

## 7. 预演（开发期执行，不等正式系统）

用《开发种子数据 v0.1》的七天场景矩阵 + 后台导出（开发期用 demo 代）预填比对表，完整走一遍"A/B/C/D 分类 → 闭环 → 通过率计算"——目的是提前暴露比对表设计的缺陷。TK-33 完成判据含预演一次。

## 8. 与台账联动

- 双轨启动：DEP-09 状态 📌 → 🚧；双轨通过 → ✅（回写时同步修订记录）
- 比对中发现的规格问题：**先台账新增/修订规格，再改系统**（顺序不可反）
- ❓ 两项（达标线 98%、双轨期 14 天）经科长确认后回写本表并升版本
