## 八、核实回归（1 条）与上线后运营手册

### DATA-12 液氧单位核实后回归（❓）

现场确认单位（疑 m³ / 吨 / 液位米）→ 改 `lo_unit` 配置 → 阈值 2.0 / 降幅 0.8 / 换罐线 2.5 及全部用量字段联动修正 → **全量回归自动用例** → 台账 DATA-12 转正、待确认清单销项。

### 运营手册（双轨转单轨后按此节奏运营）

| 周期 | 事项 | 出处 | 步骤与标准 |
| --- | --- | --- | --- |
| 每日 | 备份任务与三告警（服务存活 / 磁盘水位 / 同步失败率）自动运行 | 技术方案 §7 | 科长收站内通知即处理，无需人工巡检 |
| 每月 | 五项成功度量出数：电子交接率 / 填写耗时 / 确认完成率 / 可追溯率 / 异常标记率 | DEP-11、《埋点与度量清单 v0.1》 | 按口径表 SQL 出数；30 / 60 天窗口指标达标即 DEP-11 ✅ |
| 每月 | 预警准确率复盘（Phase 2 起） | C-07、DEP-11 反指标 | 导出当月 alerts → 科长逐条标"真实异常 / 误报" → 计算准确率 → 阈值调整走配置中心（留审计） |
| 每季度 | 备份恢复演练 | 技术方案 §7 | 随机取一日备份 → 恢复到隔离环境 → 抽查记录完整 → 演练记录归档（备份不演练等于没有） |
| 随时 | 账号开通 / 停用 | F6-02、C-05 | 仅经后台操作并写审计；一人一号 |
| 随时 | 任何配置变更 | C-04 | 一律走配置中心 + 审计，**禁止直改数据库** |
| 随时 | 规格变更维护 | 台账纪律 | 先台账后执行层；改完运行 `node scripts/check-ledger.mjs` |

### DEP-12 微信群过渡的退出条件

Phase 2 站内推送上线，**且**预警准确率连续一个月达标（C-07 复盘数据）→ 停止人工转发，DEP-12 转 ✅。

## 使用说明

1. 每项验收 = 步骤走完 + 通过标准达成 + 验收人签字 / 日期（电子或纸质均可，随上线材料归档）
2. 验收中发现缺陷：记入缺陷清单（编号 `BUG-序号`，与双轨比对规格 §3-D 同源），修复后复验本项
3. ⏸ / ❓ 项不阻塞 Phase 1 发布，但**阻塞其所属 Phase 的发布核对**
