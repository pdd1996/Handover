## 七、使用方式与生产边界

1. **开发**：`db:migrate && db:seed` 一键从零建库（TK-02 交付判据）
2. **测试**：E2E 启动前按场景矩阵装载子集；时间相关用例（F2-11/12、F6-06）以 D-1/D-2 为基准注入时间
3. **生产边界**：种子数据**严禁**进入生产——生产初始化走 DEP-09 上线流程（与科长确认全部阈值/基数/字典/清单后录入）；❓ 占位值确认后改 configs，不改表结构与代码
4. **占位值更新纪律**：每项 ❓ 闭环时，先改本表并升版本，再同步种子脚本——本表是种子数据的唯一出处
