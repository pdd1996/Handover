# Handover · 决策记录（Decision Log）（v1.1）

- **定位**：记录项目一路走来**每个关键决策"是什么、为什么、当时还考虑过什么"**。交接时若有人问"当初为什么这么定"，翻这里；改需求前先看这里，避免推翻决策而不自知。
- **关联文档**：《PRD v0.2.8》（需求）、《技术方案 v0.2》（实现）、《规格编号与验收对照表 v1.4》（验收）；本文件与三者互补——它们写"是什么/怎么实现/怎么验收"，本文件写"为什么"。
- **编号规则**：`D-` 前缀 + 类别 + 序号（D-P 产品、D-T 技术、D-M 流程）；**编号只增不复用**，作废的决策保留编号并标 ⛔，与台账纪律一致。
- **生成时间**：2026-08-31（v1.1，汇总自 PRD/技术方案各版修订记录与历次讨论）

**状态符号**：✅ 已定案（已落稿/已实现）｜🔓 已定案但待外部确认（信息科等）｜⛔ 已作废（保留备查）
